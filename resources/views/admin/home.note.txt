-Middleware 中介層
1. 修改 config/session.php
   將'expire_on_close' => env('SESSION_EXPIRE_ON_CLOSE', false) 的 false 改為 true
2. 建立 Middleware: php artisan make:middleware CheckManager
   會在 app/Http 下新增一個 Middleware 資料夾, 並在資料夾中生成 CheckManager.php
3. 編輯 CheckManager.php
4. 開啟 bootstrap/app.php
   ->withMiddleware(function (Middleware $middleware): void {
        // 在這裡加上 CheckManager
        // 'manager': 路由中會用到的名稱, 用 manager 代表 CheckManager.php
        $middleware->alias([
            'manager' => CheckManager::class
        ]);
    })
5. 開啟路由 routes/web.php
   將後台的路由加上 middleware('manager')
